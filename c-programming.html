About This Course

C is a programming language that helps learners understand the fundamentals of computer programming.

This course introduces programming concepts through simple examples and practice exercises suitable for beginners.

What You Will Learn

  • Structure of a C program
  • Variables and data types
  • Operators and expressions
  • Conditional statements
  • Loops and arrays
  • Functions and pointers basics
  • Structures and mini projects

Course Content

Study each topic and practise writing programs on your computer.

  1. Introduction to C

    Learn about C, compilers and program structure.

  2. First C Program

    Write a simple program using printf().

  3. Variables and Data Types

    Understand int, float, char and constants.

  4. Input and Output

    Use printf(), scanf() and format specifiers.

  5. Operators

    Arithmetic, relational and logical operators.

  6. Decision Making

    Learn if, if-else and switch.

  7. Loops

    Practise for, while and do-while.

  8. Arrays and Strings

    Store and process multiple values.

  9. Functions and Pointers

    Understand reusable functions and pointer fundamentals.

  10. Mini Project

    Build a menu-driven calculator using C.
