About This Course

Web development is the process of creating websites and web applications.

In this course, you will learn how HTML structures a webpage, CSS styles the page, and JavaScript adds interactive features.

What You Will Learn

  • HTML elements and webpage structure
  • Links, images, tables and forms
  • CSS colours, layouts and typography
  • Flexbox and responsive web design
  • JavaScript fundamentals
  • DOM manipulation and events
  • Building and publishing a website

Course Content

Follow the lessons in order and practise each concept by creating webpages.

  1. Introduction to Web Development

    Understand websites, browsers, servers and URLs.

  2. HTML Fundamentals

    Learn headings, paragraphs, links and lists.

  3. Images, Tables and Forms

    Add images, organise data and create forms.

  4. CSS Fundamentals

    Style webpages using colours, fonts, margins and padding.

  5. CSS Layouts

    Learn Flexbox, Grid and positioning.

  6. Responsive Web Design

    Make webpages work on mobile, tablet and desktop screens.

  7. JavaScript Fundamentals

    Understand variables, conditions, loops and functions.

  8. DOM and Events

    Respond to button clicks and update webpage content.

  9. Website Project

    Create a complete responsive multi-page website.

  10. Website Publishing

    Learn the basics of hosting and deployment.
